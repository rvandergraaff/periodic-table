# 🧪 Educational Periodic Table in LaTeX

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![LaTeX](https://img.shields.io/badge/Made%20with-LaTeX-1f425f.svg)](https://www.latex-project.org/)

A complete periodic table of elements designed specifically for **chemistry education**, created with **LaTeX and TikZ**. Ideal for high school and university teachers who need a precise and customizable pedagogical tool.

![Periodic Table Preview](preview.png)

## ✨ Key Features

### 🎓 **Pedagogical Approach**
- **Dual numbering system**:
  - Top: Modern numbering (IUPAC) 1-18
  - Bottom: Traditional system (Stock) IA-VIIIA - **essential for teaching nomenclature**
- **Colors by chemical categories** (soft pastels):
  - Alkali metals, alkaline earth metals, transition metals
  - Metalloids, nonmetals, halogens, noble gases
  - Lanthanides and actinides differentiated
- **Full element names** (no abbreviations)

### 💻 **Technical**
- **100% LaTeX/TikZ code** - compiles directly to PDF
- **Fully vectorial** - maximum quality at any size
- **Automated coordinate system** - easy to modify and extend
- **Responsive design** - automatically adjusts to page size

## 🚀 How to Use

### Requirements
- LaTeX distribution (TeX Live, MiKTeX, etc.)
- PDFLaTeX compiler

### Compilation
```bash
pdflatex periodic_table.tex
